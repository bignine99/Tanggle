# 탱글성형외과 프리미엄 카드 이미지 생성 프롬프트 가이드

이 문서는 새롭게 배열된 각 카테고리 카드(12개)의 전문적인 배경/인물 이미지를 직접 생성하실 수 있도록 정리한 프롬프트 세트입니다.
안내된 프롬프트를 복사하여 Midjourney(미드저니) 또는 DALL-E와 같은 AI 이미지 생성기에 붙여넣어 생성해 주세요.

생성된 이미지는 이 폴더(`01_raw_data\card_image`)에 **[파일명]** 에 맞춰서 1개씩(또는 4개 묶음으로) 저장해 주시면, 제가 추후 프론트엔드의 `public/images/category_bg/` 경로로 복제하여 코킹에 탑재하겠습니다.
